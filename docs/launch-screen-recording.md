# ByteToken Playground launch recording

This file intentionally contains no platform-specific launch copy. It only documents the reusable public demo capture so future recordings stay technically accurate.

## Primary demo — 20–35 seconds

1. Open `https://bytetoken-playground-kcwc.vercel.app` with the browser at a clean zoom level.
2. Show the visible scope chips briefly: **Encoding ≠ compression**, **Direct ID is local-only research**, **No model-understanding claim**.
3. Select the JSON example and keep `o200k_base` selected.
4. Click **Analyze + verify transport**.
5. Hold on the Base64 and ByteToken Standard cards long enough to read the measured token counts and the lossless round-trip badges.
6. Scroll just enough to show that LZMA is reported in a separate compression section.
7. Finish with the GitHub + Paper PDF links visible.

Recommended on-screen caption: `Measured with real tokenizer counts · byte-for-byte round trip verified`

Do not add an unscopeable headline such as `40% fewer tokens everywhere`.

## Capture variants

- **Vertical (9:16):** LinkedIn, X, Threads and short-form social. Crop around the payload controls and result cards; 20–35 seconds.
- **Landscape (16:9):** GitHub README, technical article embeds, Product Hunt/media kit; browser-width capture with the full comparison visible.
- **Still screenshots:** hero/input, measured JSON result, compression separation, and optionally the random-byte control.

## Recording quality

- 1080p or higher.
- 30 or 60 fps.
- Hide bookmarks, personal tabs, notifications and account avatars where possible.
- No narration is required; a clean cursor-led recording works well.
- Prefer one continuous take over rapid cinematic cuts because the goal is reproducibility, not an ad impression.
