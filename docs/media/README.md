# ByteToken Playground media

This directory contains screenshots and a screen recording of the public ByteToken Playground:

https://bytetoken-playground-kcwc.vercel.app/

The captures use a 1364×680 browser viewport, the built-in JSON example, and `o200k_base`.

Files:

- `01_hero_and_paper_links.png` — Playground overview, scope guardrails, GitHub, and paper links.
- `02_measured_transport_comparison.png` — measured transport comparison after a verified analysis.
- `03_compression_and_scope.png` — compression results and scope guardrails.
- `bytetoken-playground-demo.mp4` — screen recording of the same Playground flow.
- `SHA256SUMS` — SHA-256 hashes for the current media files.

The media is illustrative. Token counts and latency values shown in a capture are specific to that payload and run. Benchmark claims should use the reproducible benchmark suite rather than values read from screenshots or video.
