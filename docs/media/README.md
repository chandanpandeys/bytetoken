# ByteToken Playground media

This directory contains real browser captures of the public ByteToken Playground at:

https://bytetoken-playground-kcwc.vercel.app/

The media is generated by `.github/workflows/capture-playground-media.yml` using a 1364×680 Chromium viewport and the public JSON → `o200k_base` → **Analyze + verify transport** flow.

Published files:

- `01_hero_and_paper_links.png` — hero, scope guardrails, GitHub, Paper PDF, and paper-source links.
- `02_measured_transport_comparison.png` — the measured transport results after the live analysis completes.
- `03_compression_and_scope.png` — the separate compression layer and research-scope guardrails.
- `bytetoken-playground-demo.mp4` — the recorded browser interaction covering the same flow.
- `SHA256SUMS` — hashes generated in the same GitHub Actions run as the media.

These are demonstration captures, not additional benchmark evidence. Token counts and timing fields visible in a capture belong to that live run. Compression remains a separate layer from ByteToken representation, and Direct ID remains a local token-ID experiment unless a target interface explicitly supports such IDs.
