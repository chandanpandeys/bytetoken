# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in ByteToken (such as an encoding corruption, denial-of-service vector in atom scanning, or memory safety issue in the Rust native extension), please do not open a public issue.

Instead, please send an email to **humanchandanpandey@gmail.com** with details of the vulnerability and steps to reproduce.

We will acknowledge receipt within 48 hours and work with you to release a patch promptly.
